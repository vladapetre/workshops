3. Liskov Substitution Principle (LSP)

Objective: Subtypes must be substitutable for their base types.

Exercise:

    Create an interface or abstract base class for weather forecast models (e.g., IWeatherForecast).

    Implement a new forecast type (e.g., DetailedWeatherForecast with extra properties such as humidity or wind speed).

    Update the service and controller to work with the base type, ensuring the new type can be substituted without breaking functionality.
