2. Open/Closed Principle (OCP)

Objective: Classes should be open for extension, but closed for modification.

Exercise:

    Introduce a new requirement: support multiple temperature scales (Celsius, Fahrenheit, Kelvin).

    Refactor the WeatherForecast class so that adding new temperature conversions does not require modifying the class itself.

    Implement this using interfaces or inheritance, allowing for easy extension with additional scales in the future.
